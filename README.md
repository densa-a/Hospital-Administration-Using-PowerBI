# 🏥 Hospital Administration using Power BI

## 📌 Project Overview

This project focuses on hospital administration and healthcare data analysis using Power BI. It uses patient, doctor, appointment, and treatment data to explore hospital operations and support data-driven decision-making.

## 🎯 Objectives

- Analyze patient information and hospital activity.
- Explore appointment records and treatment details.
- Understand doctor-related information.
- Identify useful patterns in hospital operations.
- Present key information through an interactive Power BI dashboard.

## 📂 Dataset Overview

The project contains four CSV files:

- **patients.csv** – Patient-related data.
- **doctors.csv** – Doctor-related data.
- **appointments.csv** – Appointment records.
- **treatments.csv** – Treatment-related data.

## 🛠️ Tools & Technologies

- **Power BI** – Dashboard development and visualization.
- **Power Query** – Data preparation and transformation.
- **CSV** – Dataset file format.

## 📊 Key Analysis Areas

- Patient analysis
- Doctor analysis
- Appointment analysis
- Treatment analysis
- Hospital operational insights

## 📈 Project Outcomes

- Organized hospital data for analysis.
- Explored relationships between patients, doctors, appointments, and treatments.
- Presented healthcare information in a visual format.
- Practiced data analysis and dashboard development using Power BI.

## 🚀 Future Enhancements

- Add more healthcare performance indicators.
- Include monthly and yearly appointment trends.
- Analyze doctor workload and treatment patterns.
- Enhance the dashboard with additional filters and interactive visuals.
